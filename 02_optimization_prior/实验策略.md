现有实验主要检验：**在相同搜索空间、试验预算和优化器下，加入大模型提供的几何相关初始点，能否改善多目标网格优化的收敛过程和最终结果。**

**1. 参数空间：4 个连续变量＋3 个二元变量**

单元类型固定为 ETri，不参与搜索。

| 参数                 | 范围或取值              | 含义                                 |
| -------------------- | ----------------------- | ------------------------------------ |
| `surface_size_ratio` | \([0.02,0.10]\)         | 表面尺寸与模型特征长度之比 \(h_s/L\) |
| `growth_ratio`       | \([1.05,1.50]\)         | 网格尺寸增长率                       |
| `refinement_angle`   | \([15^\circ,60^\circ]\) | 曲率细化角度                         |
| `tet_size_ratio`     | \([1,4]\)               | 最大四面体尺寸与表面尺寸之比         |
| `curvature`          | \(\{0,1\}\)             | 曲率细化开关                         |
| `fastaft`            | \(\{0,1\}\)             | 快速推进前沿开关                     |
| `conformal`          | \(\{0,1\}\)             | 共形处理开关                         |

其中，\(L\) 取导入 CAD 几何包围盒的对角线长度，实际尺寸按下式换算：

\[ h_s=\texttt{surface\_size\_ratio}\,L,\qquad h_{t,\max}=\texttt{tet\_size\_ratio}\,h_s. \]

因此，当前是 **7 维混合参数空间**，三个二元开关共有 8 种组合。

**2. 三种优化器，每种设置 A0 与 A0′ 两组**

| 优化器   | A0               | A0′                   | 搜索方式                                               |
| -------- | ---------------- | --------------------- | ------------------------------------------------------ |
| Random   | `random`         | `random_seed`         | 全程随机采样                                           |
| ParEGO   | `parego`         | `parego_seed`         | 随机权重标量化三个目标，通过高斯过程和期望改进选择候选 |
| qLogEHVI | `qlogehvi_mixed` | `qlogehvi_mixed_seed` | 混合高斯过程建模，通过期望超体积改进选择候选           |

A0 与 A0′ 的**设计差别仅在第 1 个初始点**：

- A0：第 1 轮使用随机点。
- A0′：第 1 轮使用大模型针对该几何模型推荐的先验点。
- 第 2–4 轮：设计上保持相同模型、相同随机种子下的配对随机点。
- 第 5–20 轮：ParEGO 和 qLogEHVI 根据各自历史进行优化；Random 继续随机采样。

热身阶段共 **4 轮，包含在 20 轮总预算内**。`_seed` 表示先验初始点注入，与实验重复使用的随机数种子是两回事。

这里需要明确：**当前 A0′是大模型辅助初始化实验，大模型没有在每一轮重新决定参数。**后续选点由对应优化器完成。

**3. 大模型先验的输入**

先验生成使用模型的几何描述，包括包围盒与尺度、实体和面边数量、边长与面面积分布、曲率及曲率半径、局部间隙代理量等，同时提供参数范围、参数含义及多模型对比信息。

大模型为每个模型给出一组初始参数。这组参数用于该模型的 A0′试验，不额外增加剖分预算。

**4. 三目标联合优化**

三个目标均为越小越好的不良单元比例：

\[ \min_{\theta}\mathbf f(\theta) = \left[ r_{\mathrm{aspect\ ratio}}, r_{\mathrm{vol\ skew}}, r_{\mathrm{tet\ collapse}} \right]. \]

最终通过可行解的非支配关系构造 Pareto 前沿。ParEGO 在选点时使用标量化，但整体实验仍按三个目标评价。

运行时间单独记录，目前不作为第四个优化目标。

**5. 网格有效性与失败处理**

每次剖分后导出 BDF，检查节点引用、重复顶点与单元、退化和倒置四面体，以及面和边界连接关系。

- **检查通过**：使用实际的三个质量目标值。
- **检查不通过，`MESH_INVALID`**：计入试验预算，保留诊断信息，标记不可行，并以 \([1,1,1]\) 作为惩罚目标记录；不进入可行 Pareto 前沿。
- **执行或检查基础设施异常，`RUNNER_ERROR`**：单独记录，不作为优化目标观测。

因此，真实无效网格与运行环境故障采用不同处理。

**6. 当前完成的实验规模**

已完成两个模型：

- `i03o_m3`
- `s13o_cube_rounded_2`

每个模型采用 **6 个策略组 × 3 个随机种子（11、12、13）× 20 轮**，合计 720 条试验记录。每轮只实际评价一个参数组合；多进程用于并行运行不同的实验组。

其中 694 条通过网格检查，26 条无效记录全部来自 `i03o_m3`。

**7. 论文评价指标**

目前按以下指标比较：

| 指标                                  | 用途                                       |
| ------------------------------------- | ------------------------------------------ |
| 累积 HV 曲线                          | 比较随评价轮次变化的 Pareto 前沿质量       |
| HV-AUC                                | 比较整个预算内的收敛表现                   |
| 配对 \(\Delta\mathrm{HV\text{-}AUC}\) | 衡量相同模型和随机种子下 A0′相对 A0 的收益 |
| IGD 收敛曲线                          | 衡量与参考前沿的距离                       |
| 模型间效果异质性                      | 判断先验收益是否随几何模型变化             |
| 第 5、10、20 轮的 \(\Delta HV\)       | 比较早期、中期和最终的先验收益             |
| 运行时间、无效试验比例                | 补充说明计算开销与可靠性                   |

IGD 使用的是**同一模型下各策略结果合并得到的经验参考前沿**。当前两个模型、三个随机种子的结果可以用于初步比较，但不足以证明先验对所有模型都稳定有效。
